Swap Clicks - Fabric 1.21.11 (aucune dépendance, pas besoin de Fabric API)

Sans rien installer (GitHub Actions) :
  1. Crée un repo sur github.com
  2. Upload TOUT le contenu de ce dossier (y compris le dossier caché .github)
  3. Onglet Actions > dernier build > Artifacts > swapclicks-jar
  4. Dézippe, mets le .jar dans .minecraft/mods (avec Fabric Loader 0.18+)
